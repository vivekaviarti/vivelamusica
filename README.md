# Maria Vivekaviarti — Vive la Musica

A vintage-inspired personal music portfolio, built as an accessible, responsive static site.

## Publishing publicly (one-time setup)

1. In this repository open **Settings → Pages**.
2. Under **Build and deployment**, choose **Source: GitHub Actions**.
3. Open **Actions → Deploy portfolio to GitHub Pages** and run the workflow if necessary.
4. After the deployment succeeds, visit **https://vivekaviarti.github.io/vivelamusica/**.

## Editing

Update `index.html` to customize the biography, selected repertoire, contact links, and add verified media or event credits. The site doesn't collect visitor data through a form.

## Editorial note

The repertoire is a personal songbook, not a verified log of publicly performed productions. Images are decorative artwork, not a real artist photograph.
